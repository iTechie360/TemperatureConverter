# Temperature Converter Architecture

## Overview

The Temperature Converter is a modular C desktop application that converts
temperature values between Celsius and Fahrenheit.

The project is designed with clean software architecture principles:

- Separation of logic
- Reusable conversion library
- Testable modules
- Maintainable source structure
